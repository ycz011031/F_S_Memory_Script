# pcm-iio events for Skylake-SP / Cascade Lake (family 6, model 85).
#
# pcm-iio loads opCode-<family>-<model>.txt from the CURRENT directory, so the
# runners only pick this up because they cd into utils/ first. Run pcm-iio from
# anywhere else and it falls back to whatever file PCM installed.
#
# This is the paper's event set (opCode-85.txt, the old file name), which is
# also PCM's own SKX file. On this CPU the paper's names are accurate: the VT-d
# events count misses by walk level, unlike Ice Lake's hits by page size.
#
# Keys are limited to those both old and new PCM accept: current PCM rejects
# `divider` ("Field in -o file not recognized"), and older PCM may not know
# `unit`. utils/discover-ssd-pcie.sh checks that this host's PCM loads it.
#
# CSV columns follow the order each hname first appears below:
#   6 IB write  7 IB read  8 OB read  9 OB write
#  10 IOTLB Hit  11 IOTLB Miss  12 VT-d CTXT Miss  13 VT-d L1 Miss
#  14 VT-d L2 Miss  15 VT-d L3 Miss  16 VT-d Mem Read
#
